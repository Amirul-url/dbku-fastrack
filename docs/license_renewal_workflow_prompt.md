# License Renewal Reminder Workflow Prompt

The system must monitor every issued advertisement license and detect the approval period and expiry date.

When an issued license will expire within 3 months, the system must create the first renewal reminder and notify PT(IKL) data entry staff and supervisors. PT(IKL) must generate the advertisement license renewal reminder letter. A supervisor must verify and confirm the reminder letter before it is released to the license holder/applicant. The released reminder may be sent through web notification, email, and WhatsApp.

When an issued license will expire within 2 months, the system must create the second renewal reminder and follow the same PT(IKL) generation, supervisor confirmation, and applicant notification process.

When an issued license will expire within 1 month, the system must create the third and final renewal reminder and follow the same PT(IKL) generation, supervisor confirmation, and applicant notification process.

If the license holder/applicant still has not completed renewal payment after the license expiry date, PT(IKL) must generate a cancellation and enforcement action notice. A supervisor must verify and confirm the notice, then submit it to KB(LES) for support. After KB(LES) support is obtained, the softcopy notice must be released to the license holder/applicant as formal notification of license cancellation and enforcement action.
